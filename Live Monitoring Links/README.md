# Live Monitoring Links

This directory contains the links and configuration details for accessing the live monitoring dashboards of the APEX-UPI ecosystem.

> [!IMPORTANT]
> **Cloud Infrastructure Requirement**
> 
> The live monitoring links provided in this directory are **not accessible by default**. They will only become active and reachable **after** turning on the respective Virtual Machines in Microsoft Azure cloud. 
> 
> Ensure the Azure VMs are powered on and the services have successfully initialized before attempting to access these dashboards.

## Dashboards Included
- **PSP Switch Operations Dashboard**: Monitors transaction success rates, latency, and Kafka event throughput.
- **CBS Health Dashboard**: Monitors Core Banking System database connections and processing queues.
- **NPCI Adapter Metrics**: Tracks the heartbeat and round-trip times to the central NPCI network mock.
